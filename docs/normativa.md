# Normativa consultada

Registro de las normas, estándares y fuentes oficiales que se consultaron para el diseño: qué dice cada una, de dónde salió y si se leyó el texto oficial. Es referencia, no criterio contable: lo que dependa de interpretación va a [preguntas-contadora.md](preguntas-contadora.md) y, cuando la contadora responde, a [decisiones.md](decisiones.md).

## Estados

- Verificado: se leyó el texto o el dato completo en la fuente oficial, con URL y fecha.
- Reportado: viene de una fuente secundaria (blog, firma, gremio, curso) o de un resultado de búsqueda sin abrir, aunque sea de un dominio oficial como normograma.dian.gov.co. Se anota "snippet oficial" cuando es ese caso.
- Sin fuente: se afirmó de memoria o lo trajo un subagente cuyas fuentes no quedaron registradas.

La columna Origen da la sesión de Claude Code o el chat de claude.ai (id corto) donde se consultó. Las fechas de consulta son de 2026.
